# Five-sentence source review experiment

This branch was created from `main` for a separate comparison. The experimental reviewer is developed and tested in an independent project copy and is provided as a downloadable ZIP in the associated ChatGPT conversation.

The experiment introduces five-sentence text units, protected non-prose blocks (tables, visuals and links), edit-before-accept suggestions, word-level restoration/deletion, bracketed additions, flag/skip decisions, and review exports.

**Important:** The implementation files have **not yet been committed to this branch**. The experiment should not be represented as deployed or merged. The original PDF Split Cleaner files remain unchanged.

Initial tests used geometry adapted from a real 56-page PDF and a browser mock of PDF.js. A direct full-PDF PDF.js browser test is still needed.
